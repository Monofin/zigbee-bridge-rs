# Device profile sources

The original Rust implementation is available under MIT or Apache-2.0. The product mappings in this directory incorporate upstream device descriptions. When copying a profile or distributing the compiled tables, keep the applicable upstream notices.

| Profiles | Upstream |
|---|---|
| `lights.json` | The [ZHA light definitions](https://github.com/zigpy/zha/blob/2da1a5b5676158ac7b603ce6b9f42641cb90e7a0/zha/application/platforms/light/const.py) use [Apache-2.0](LICENSE-APACHE-ZHA). |
| `metering.json` | The [ZHA device-handler definition](https://github.com/zigpy/zha-device-handlers/blob/b07fa76876e081d48744968f9fb806e7f1fee0ee/zhaquirks/innr/innr_sp120_plug.py) uses [Apache-2.0](LICENSE-APACHE-ZHA). |
| VALLHORN endpoint 3 illuminance reports in `inputs.json` | The [deCONZ device description](https://github.com/dresden-elektronik/deconz-rest-plugin/blob/c24e81cf01c121583887acea24e647c3496ebd9a/devices/ikea/vallhorn_wireless_motion_sensor.json) uses [BSD-3-Clause](LICENSE-BSD-deconz). |
| Philips2 RGB-to-xy conversion in the Rust Hue handler | The pinned converters’ [colour implementation](https://github.com/Koenkk/zigbee-herdsman-converters/blob/ed29f80014f11cd3234e0e7371d1aace44e08982/src/lib/color.ts) credits [cie-rgb-converter](https://github.com/usolved/cie-rgb-converter/blob/79a9eb81abfd8126a94ff7bee69fc8daaf79d6e1/cie_rgb_converter.js). Retain both the [converters MIT notice](LICENSE-MIT-converters) and the [original MIT notice](LICENSE-MIT-cie-rgb). |
| `kelvin-xy.bin` | Generated by `tools/devices/kelvin_xy.py` from the [converter Kelvin-to-XY lookup](https://github.com/Koenkk/zigbee-herdsman-converters/blob/ed29f80014f11cd3234e0e7371d1aace44e08982/src/lib/kelvinToXy.ts) under [MIT](LICENSE-MIT-converters). |
| Converter model lists, fingerprints, commands and datapoint mappings | The [pinned zigbee-herdsman-converters definitions](https://github.com/Koenkk/zigbee-herdsman-converters/tree/ed29f80014f11cd3234e0e7371d1aace44e08982/src/devices) use [MIT](LICENSE-MIT-converters). |

These profiles adapt upstream definitions for the Rust resolver. They retain source references where a profile identifies an individual definition.
