## Protocol work still to qualify

The R8 generator now emits 124 command assignments across 18 clusters. In the locked SDK there are 417 standard-namespace command declarations outside those reviewed families, six reviewed SDK-only commands and 58 vendor/sample declarations. The 417 need comparison to the R8 assignment tables before they can count as missing standard commands. Begin the specialist passes with TA Information `0900`, IEEE 11073 Protocol Tunnel `0614`, SE Key Establishment `0800`, and Green Power `0021`. Include role, revision, direction, optional-field discriminators, a byte vector and a malformed input with each codec. [Generator](../zcl/generate.py)

At the Core/host boundary, capture commissioning and rejoin outcomes, APS confirmations, duplicate delivery and endpoint discovery separately from the cluster tests. Exercise an interrupted key exchange, a changed network address and an adapter restart with pending requests. Green Power additionally needs persistent sink/proxy pairing state and frame counters. For each claim record which result came from the NCP and which behavior the Rust host verified. These are acceptance cases for future work.
